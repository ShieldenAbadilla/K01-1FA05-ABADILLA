**2D Distance Calculator**

This Python program calculates the Euclidean distance between two points on a 2D coordinate plane. The user enters the x and y coordinates of both points, and the program calculates and displays the distance.

**How to Run the Program**
- Make sure Python is installed.
- Open the program in a Python editor or IDE.
- Run the program.
- Enter the coordinates when prompted.
  
**The program requires four values:**
- x1 – x-coordinate of the first point
- y1 – y-coordinate of the first point
- x2– x-coordinate of the second point
- y2 – y-coordinate of the second point

**Sample Output**
- Enter x1: 1
- Enter y1: 2
- Enter x2: 4
- Enter y2: 6
- Distance: 5.00
