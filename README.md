2D Coordinate Distance Calculator

Description
A simple Python program that calculates the Euclidean distance between two points in a 2D coordinate system (x₁, y₁) and (x₂, y₂) using the standard distance formula powered by Python's built-in `math` library.
 
How to Run the Program
1. Ensure you have Python installed.
2. Save the code into a file named `distance_calculator.py`.
3. Open your terminal or command prompt.
4. Navigate to the folder where the file is saved.
5. Run the program.

## Input Needed
The program requires four numerical inputs (integer or decimal)
x1: The X-coordinate of the first point.
y1: The Y-coordinate of the first point.
x2: The X-coordinate of the second point.
y2: The Y-coordinate of the second point.
